# Sekolah Suite — unduhan

Pemasang resmi Sekolah Suite: Naskara (persuratan), Rosterio (jadwal), Siswapala (kesiswaan),
dan Sarprasio (sarana prasarana) dalam satu program.

Unduh versi terbaru di halaman **Releases** (kanan halaman ini):

- `SekolahSuite-Setup-x.y.z.exe` — komputer sekolah Windows 10/11, klik dua kali untuk memasang.
- `sekolah-suite-x.y.z-linux-x64.tar.gz` — server Linux atau VPS, jalankan `sudo ./pasang.sh`.

Gratis dicoba 45 hari. Bantuan dan pembelian: lihat website Sekolah Suite.
